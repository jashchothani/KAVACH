## 🛡️ What is KAVACH?

**KAVACH** (कवच — *shield*) is a unified **AI-driven SOAR + XDR platform**. It watches endpoint behavior, detects threats with rules **and real ML**, correlates evidence into incidents, explains them in plain language, and responds with **controlled, auditable, reversible** actions.

> 🌐 **Official website: [www.kavachcybertech.in](https://www.kavachcybertech.in)**

## 🧬 How It Works

**Every high-impact response follows:** `authorize → dry-run → human approval → execute → audit → rollback`

```mermaid
flowchart LR
    A["🚨 Incident"] --> B["🔐 Authorize"] --> C["📘 Playbook"] --> D["🧪 Dry Run"] --> E["👤 Approval"] --> F["⚡ Execute"] --> G["📜 Audit"] --> H["↩️ Rollback"]
    style A fill:#2b0a14,stroke:#FF3B6B,color:#fff
    style F fill:#06261a,stroke:#00FF9C,color:#fff
    style H fill:#1a0f2e,stroke:#8B5CF6,color:#fff
```

**AI failure ≠ security failure:** `NVIDIA NIM → local provider → heuristic fallback → KAVACH keeps protecting`

## 🚀 Quick Start

```bash
git clone <YOUR_REPOSITORY_URL> && cd KAVACH/backend
python -m venv venv && venv\Scripts\activate     # Windows
pip install -r requirements.txt
copy .env.example .env                           # add your own keys
python main.py                                   # full XDR mode
python main.py --no-collectors                   # lightweight dev mode
```

```bash
cd frontend && npm install && npm run dev        # React SOC
cd mobile   && flutter pub get && flutter run    # Flutter client
```

> 🔐 Never commit real credentials, API keys, tokens, or passwords.

| Service | Location |
|---|---|
| 🛡️ Backend API | `localhost:8000` |
| 📚 Swagger • ReDoc | `localhost:8000/docs` • `/redoc` |
| 🌐 React SOC | `localhost:5173` |
| 🖥️ Terminal UI | `python tui.py` |
