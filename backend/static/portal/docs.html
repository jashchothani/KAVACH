KAVACH Platform Documentation

Welcome to the official developer and SecOps documentation for KAVACH ΓÇö the enterprise AI-driven Security Orchestration, Automation, and Response (SOAR) and Extended Detection and Response (XDR) platform.

1. Platform Quickstart

KAVACH is designed for zero-friction deployment. The cloud analysis engine and native SOC command center run together seamlessly on a single port. 

# 1. Start the Unified KAVACH Server (FastAPI + Native SOC Dashboard)
start_kavach.bat

# Or run via Python directly:
cd backend
python -m uvicorn app.main:create_app --host 0.0.0.0 --port 8000 --factory

The server automatically mounts the native HTML5/CSS3/JavaScript frontend and serves it directly at http://localhost:8000/ with interactive Swagger documentation at http://localhost:8000/docs.

2. Distributed Pipeline Architecture

KAVACH separates telemetry collection from intensive correlation analysis:

  • Endpoint Collectors: Lightweight agents run on Windows, Linux, and macOS endpoints, sampling 16 sensors and spooling locally into a high-speed SQLite ring buffer.
  • 5-Tier Priority Queue: Events are sorted into Critical, High, Medium, Low, and Statistical streams before shipment. Critical telemetry is guaranteed zero drop and sub-millisecond priority routing.
  • Cloud Analysis Engine: A central pipeline applies rule heuristics and an unsupervised Isolation Forest ML model (scikit-learn) trained on 98,000+ behavior samples.
  • Autonomous SOAR: Triggers network isolation, process termination, and canary tripwires.

3. The 16 Telemetry Sensors

The endpoint collector agent houses 16 specialized modular sensors:

  1. Process Sensor: Monitors process creation, parent-child hierarchies, and command-line arguments.
  2. Network Sensor: Captures established TCP/UDP sockets, remote ports, and high-entropy destinations.
  3. FIM File Monitor: Real-time watchdog monitoring System32, SysWOW64, Temp, and startup locations.
  4. Login & Auth Sensor: Tracks Windows EventLog 4624 (logon) and 4625 (failed brute-force).
  5. PowerShell Sensor: Parses Event ID 4104 ScriptBlock logs for Base64 and AMSI bypasses.
  6. Service Sensor: Detects creation or modification of Windows system services.
  7. USB Removable Sensor: Intercepts USB mass storage insertion and serial fingerprints.
  8. Windows Defender: Polls antivirus signature updates, RTP status, and quarantined threats.
  9. DNS Query Sensor: Tracks domain resolutions for DGA (Domain Generation Algorithms) detection.
  10. Registry Sensor: Inspects Run, RunOnce, and Winlogon persistence registry keys.
  11. Scheduled Task Sensor: Captures cron and Windows Task Scheduler creations.
  12. Software Sensor: Audits installed packages and unexpected binary drops.
  13. System Info Sensor: Tracks CPU, memory usage, and hardware vitals heartbeat.
  14. Sysmon Sensor: Integrates Microsoft System Monitor deep kernel telemetry.
  15. Canary Sensor: Deploys decoy honeypot files to detect active ransomware encryption.
  16. Windows EventLog: Generic parser for Windows Security and Application channels.

4. REST API Reference

KAVACH provides fully versioned OpenAPI 3.0 REST endpoints:

GET /api/v1/telemetry/hosts

Returns the live status of all registered endpoint machines.

curl -X GET http://localhost:8000/api/v1/telemetry/hosts \
  -H "Accept: application/json"

POST /api/v1/telemetry/events

Ingests a batch of telemetry events from an endpoint agent:

curl -X POST http://localhost:8000/api/v1/telemetry/events \
  -H "Content-Type: application/json" \
  -H "X-Agent-Token: your_agent_token" \
  -d '{
    "host_id": "srv-dc01",
    "timestamp": "2026-10-13T10:00:00Z",
    "events": [
      {
        "collector": "powershell",
        "edge_tier": "critical",
        "command_line": "powershell.exe -enc SQBFAFgA...",
        "risk_score": 95.0
      }
    ]
  }'

POST /api/v1/url/scan

Performs instant lexical and reputation scanning on target URLs.

curl -X POST http://localhost:8000/api/v1/url/scan \
  -H "Content-Type: application/json" \
  -d '{"url": "https://suspicious-login-auth.net"}'

5. Live WebSocket Stream

Connect to the continuous live stream endpoint at ws://localhost:8000/api/v1/dashboard/live to receive real-time detection events and system metrics with zero polling overhead. 

const socket = new WebSocket('ws://localhost:8000/api/v1/dashboard/live');

socket.onmessage = (event) => {
  const telemetry = JSON.parse(event.data);
  console.log('Live Alert:', telemetry);
};
