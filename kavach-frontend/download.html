Step-by-Step

Detailed Installation Guides

Follow these exact steps to deploy and activate KAVACH on your systems.

🪟 How to Install KAVACH on Windows 10 & 11

1

Download and Verify

Download KAVACH-Setup-2.1.0.exe from the releases section above. Optionally run the PowerShell SHA-256 command to verify file integrity.

2

Launch Installer & Windows SmartScreen

Double-click KAVACH-Setup-2.1.0.exe to begin installation.

⚠️ Windows SmartScreen Note: Because this is an enterprise sovereign binary signed with an internal corporate certificate, Windows SmartScreen may show "Windows protected your PC". Click "More info" and then click "Run anyway" to proceed.
3

Approve User Account Control (UAC) Elevation

When the Windows UAC elevation prompt appears, click "Yes". Administrator privileges are strictly required to register the Session 0 background telemetry collector and configure real-time OS monitoring hooks.

4

Choose Installation Directory

The setup wizard will install the binaries to C:\Program Files\KAVACH (or your custom directory). It installs the Flutter High-DPI Desktop client, the native System Tray Guardian, and the 16 real-time sensor collectors.

5

Automatic Tray Guardian Activation

Upon installation completion, the high-tech KAVACH Shield icon will appear in your Windows Taskbar System Tray (Notification Area). Click it once to inspect live protection status or access the full Sovereign Desktop Console.

📱 How to Install KAVACH Mobile Companion (Android)

1

Download APK File

Tap the Download Android APK button on your mobile device to download kavach-mobile-release.apk.

2

Enable "Install Unknown Apps" in Settings

Open your file manager or browser downloads. When prompted by Android that the application is from an external source, tap Settings and toggle on "Allow from this source".

3

Install and Grant Permissions

Tap Install. Once installed, open KAVACH Mobile. Allow Notification permissions so that emergency containment alerts reach your lockscreen in real time.

🧩 How to Install Browser Threat Intelligence Extension

1

Extract Extension ZIP

Download kavach-extension.zip and extract the contents to a folder on your machine (for example, C:\KAVACH\extension).

2

Open Chrome / Edge Extensions Page

In Google Chrome, Microsoft Edge, or Brave, open a new tab and navigate to chrome://extensions or edge://extensions.

3

Enable Developer Mode & Load Unpacked

In the top-right corner, toggle the switch for "Developer mode" to ON. Click the "Load unpacked" button and select the extracted extension folder.

4

Pin and Enjoy Real-Time Link Safety

Pin the KAVACH Shield icon to your browser toolbar. Now when searching Google or Bing, every result will display a verified green tick (✓) or red threat badge (✗) with an interactive threat summary!
