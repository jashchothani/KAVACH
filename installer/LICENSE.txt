3. SECURITY ARCHITECTURE
------------------------

3.1 Telemetry Pipeline. The Endpoint Collector uses a 16-sensor telemetry
pipeline that observes system processes, network sockets, file-system
integrity, Windows Defender status, firewall state, and hardware posture.

3.2 Cryptographic Identity. Device identity is anchored using the Windows Data
Protection API (DPAPI) and RSA-2048 hardware-bound key pairs. Device
authorization keys are held in Windows protected storage and are never
transmitted in plaintext.

3.3 Data Handling in Transit and at Rest. Telemetry is normalized and, during
network disruption, buffered in a local SQLite Write-Ahead Log (WAL) spool.
Data in transit is protected using TLS 1.3 with AES-256-GCM.

3.4 Multi-Tenant Isolation. The platform enforces tenant isolation so that
each user and enrolled Device can access only its authorized telemetry,
incidents, and audit trails.
